# ORVEXA brand assets

The approved mark and wordmark are in [ORVEXA.png](../ORVEXA.png). No original
SVG was found. The new files reconstruct its white front-face contours as real
SVG paths, with no embedded bitmap. They are **vector reconstructions**, not a
claim to have recovered the designer's vector master. No replacement emblem
or extra eye was added. The PNG was not modified.

- [Symbol](../web/public/brand/orvexa-symbol.svg)
- [Wordmark](../web/public/brand/orvexa-wordmark.svg)
- [Horizontal lockup](../web/public/brand/orvexa-logo.svg)

`scripts/trace-brand.py` records crops/contour simplification for reproduction
using Python + Pillow; shipped SVGs need no Python at build/runtime. Purple
extrusion, poster slogans and background are excluded. Reference text is not a
product claim; v1 is not labelled private or decentralized. The other attached
image guides color only; its symbol does not replace ORVEXA.

Exact user palette in [tokens.css](../web/src/tokens.css): Obsidian `#050608`,
Midnight Navy `#101A27`, Deep Blue `#1B2B3D`, Steel Blue `#334B65`, Slate Blue
`#526D89`, Ice White `#E6F2FF`, Secondary Text `#9AA9BA`, Borders `#253243`.
No red/purple/neon/glow. [DESIGN.md](../DESIGN.md) records the built components.
ORVEXA remains a provisional working name.
