In this release

A working foundation.
On your computer.

Wallet

Your keys stay with you.

Create an encrypted wallet, receive an address and QR code, sign transfers locally, and keep an encrypted backup. V1 recovery uses a file and password; seed phrases come later.

Node

Verify. Store. Relay.

Start a real Rust full node from the app. Exchange signed transactions and blocks over TCP / Noise. Stop and resume against the same saved chain.

Explorer

Check what happened.

Inspect real blocks, find a transaction by hash and check its inclusion. The Explorer shows the public information the current protocol provides.

Getting started

From download
to your own node.

No cloud account, paid subscription or VPN. Participants supply the computers and connectivity.

  1. 1

    Open ORVEXA.

    Download the Windows app or ZIP. The node and interface are included. Rust and Node.js are not needed to run it. Create a wallet locally and save its encrypted backup.

  2. 2

    Choose the same network.

    Import the operator’s public genesis.json and network.json. Verify the chain ID independently. Joining never silently creates a different chain.

  3. 3

    Start your node.

    Press Start node. The node runs in the app’s background while you use Wallet and Explorer. Keep ORVEXA open; closing this preview stops its node.

i

The public network is not live yet.

A reachable seed and a common network configuration are still needed. V1 confirmations require the configured block authority. A full node does not automatically become a block-producing validator or earn rewards.

The direction

Private by default.
Open by your choice.

This is the goal for the next ledger, not a property of the current preview. Amounts and balances should stay private, with deliberate disclosure when their owner chooses.

Private transfers & balancesPlanned

Already public data cannot be made secret retroactively. Disclosed viewing information cannot be erased from someone else’s copy.

For operators

A server is welcome.
So is an ordinary PC.

Windows users can run the node inside the app. Native macOS support and a universal build script are in source; a verified Mac download is not available yet. Linux operators can build the headless Rust node. Reachable participants help others join; outbound connections work for ordinary nodes behind NAT.

Windows & Linux instructions ↗
Build from source
git clone https://github.com/waxiechc/orvexa.git
cd orvexa
cargo build --release --locked \
  -p orvexa-node -p orvexa-cli

Use the common genesis and operator-provided seed. This command builds the node; it does not create a live public network.
