# Локализация и совместимость

Русский — основной язык приложения, сайта, README и текущих пользовательских
инструкций. В приложении RU/EN меняется без перезапуска и сохраняется в
`orvexa.locale`. Сайт имеет отдельную English-страницу `en/`; тексты доступны
без JavaScript. Внешние диалоги выбора файлов используют язык ОС.

`web/src/locales/ru.json` содержит русские тексты, `i18n.ts` — выбор языка,
подстановки и форматирование представления. Английский исходный текст — ключ.
Переводятся видимые состояния, формы, accessibility labels, сообщения ошибок,
резервное копирование и поиск. Техническая диагностика неизвестных библиотек
или ОС может оставаться в исходном виде; распространённые ошибки node/wallet
имеют русский перевод. Юридические notices не переводятся.

Пути API, JSON ключи/enums, хеши, chain ID, адреса, подписи, seed/key материал,
версии и команды не локализуются. Названия кошельков — пользовательские данные,
не ключи словаря. Количество атомов форматируется из BigInt, без округления
через Number. Переключение языка не мигрирует данные и не меняет транзакции.

Проверки включают создание, ошибку пароля, encrypted backup, проверку файла в
CLI, восстановление в другом профиле, все страницы, RU/EN с перезагрузкой и
сохранение пользовательского названия. Работающая v1 остаётся прозрачной.

Параллельные `.en.md` сохраняют английскую документацию предыдущего выпуска;
исторические проверки находятся в VALIDATION.en.md. Основные актуальные
пользовательские инструкции — DESKTOP_APP.md, WEB_WALLET.md, NATIVE_P2P.md и
MACOS.md. Макет, палитра и геометрия логотипа сохранены.
